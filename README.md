# Animal Mating Marketplace Blueprint

This repository contains the business, market, product, architecture, integration, and execution blueprint for a Pakistan-first animal mating and breeding marketplace with USA expansion readiness.

## Documentation Reading Order

1. `Context.md` - business overview, assumptions, phases, and architecture.
2. `MarketPlan.md` - Pakistan/USA research, TAM/SAM/SOM, GTM, roadmap, costs, and risks.
3. `Features.md` - detailed role and feature specifications.
4. `Rule.md` - development standards, business rules, compliance rules, and safety rules.
5. `IntegrationGuide.md` - folder structure, database schema, API contracts, security, and deployment workflow.
6. `Integration.md` - external service providers and integration boundaries.
7. `Pricing.md` - monetization model and payment strategy.
8. `Setup.md` - environment setup, CI/CD, infrastructure, backup, and disaster recovery.
9. `Skill.md` - required technical and domain capabilities.
10. `Agent.md` - agent roles and development workflow.
11. `Claude.md` - instructions for Claude/Cursor coding agents.
